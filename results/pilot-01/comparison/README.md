# Retired evaluation report (version 1)

The old own-baseline, speedup-factor, bound-marker and A-cgroup figures are archived under `retired/`. Historical CSV/JSON files remain here unchanged for compatibility; their normalization must not be confused with report-v2 ordinary percent reductions/increases.

Current offline report: [evaluation-redesign/historical](../../evaluation-redesign/historical/evaluation.md).

Important: the old A used dedicated default-valued cgroups. It is NOT the newly requested no-cgroup A. The new report rejects it unless historical diagnostics are explicitly requested, and marks every resulting figure accordingly. Synthetic rendering fixtures are separate and are not experimental evidence.

No new benchmark, tuning loop or kernel change was run to redesign these plots.
